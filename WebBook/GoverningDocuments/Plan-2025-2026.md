# Computational Geodynamics Primer: Development Plan

## Core Concept: Vertical Strand Demonstration

Create one complete pathway through the book to demonstrate the pedagogical approach before expanding horizontally to other topics.

## Structure: Modular Content Units

Each topic consists of **2-3 page modules** that combine:
- Core text and equations
- Interactive Jupyter notebooks (via Binder)
- Teaching slides (where appropriate)
- Background reading references
- Exercises and applications

## First Vertical Strand: From Fundamentals to Applications

## Implementation Strategy

### Step 1: Create Module Template
- Establish consistent format for all modules
- Define standard components (text, equations, code, exercises)
- Create example module as reference

### Step 2: Mine Existing Content
Pull from current draft material:
- `ThermalConvection.qmd` → Theme 2 content
- `NavierStokes.qmd` → Theme 3 content
- `ContinuumMechanics.qmd` → Background mathematics
- Numerical methods chapters → Notebook implementations

### Step 3: Develop Notebooks
For each theme, create:
- Simple demonstration notebooks (basic concepts)
- Exploration notebooks (parameter studies)
- Application notebooks (real-world problems)

All notebooks will:
- Use standard `.ipynb` format
- Include Binder configuration for dependencies
- Contain inline documentation and exercises

### Step 4: Integration
- Link modules within each theme
- Create clear learning pathways
- Add navigation between related concepts
- Ensure consistent notation throughout

## Success Criteria

A complete vertical strand demonstrates:
1. Clear progression from fundamentals to applications
2. Seamless integration of theory and computation
3. Modular structure allowing flexible use
4. Practical geodynamic relevance
5. Reproducible computational examples

## Expansion Strategy

Once the first vertical strand is complete:
1. Evaluate the modular approach effectiveness
2. Identify reusable patterns and templates
3. Expand horizontally to additional themes:
   - Elastic deformation
   - Fluid dynamics
   - Reactive transport
   - Numerical methods deep-dives

## Key Principles

- **Modularity**: Each unit is self-contained but connected
- **Practicality**: Every concept links to Earth applications
- **Computability**: All examples are reproducible via Binder
- **Accessibility**: Multiple entry points for different backgrounds
- **Flexibility**: Instructors can select and reorder modules

## Technical Requirements

### For Notebooks
- Binder environment configuration
- Required packages list (NumPy, SciPy, Matplotlib minimum)
- Testing protocol for notebook execution
- Version pinning for reproducibility

### For Content
- Consistent mathematical notation
- Clear figure labeling and references
- Complete bibliography for each module
- Accessible alt-text for all figures
